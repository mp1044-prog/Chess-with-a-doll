# Кукольные шахматы

Пиксельная хоррор-партия в шахматы против фарфоровой куклы. Над столом зажигается лампа, из темноты появляются её шарнирные руки. Они стучат ногтями, сами переставляют фигуры и не любят, когда к ним заглядывают. Всё остальное скрыто в темноте.

![Кукла смотрит из темноты](screenshots/doll_face.png)

## Как запустить

Игра — это один файл `index.html`, без сборки и без зависимостей.

- **Локально:** скачайте `index.html` и откройте его в браузере.
- **Онлайн через GitHub Pages:** в репозитории откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Нужен браузер с поддержкой **WebGL2**: свежие Chrome, Edge, Firefox или Safari, на компьютере или телефоне.

## Как играть

- В начале кукла прячет в кулаках белую и чёрную пешку. Нажмите прямо на кулак: цвет пешки в нём станет вашим цветом.
- Нажмите на свою фигуру, затем на подсвеченную клетку, чтобы сделать ход. Ходы куклы делают её руки.
- Действуют все правила шахмат: рокировка, взятие на проходе, превращение пешки, шах, мат и пат.

### Управление

| Действие | Телефон | Компьютер |
|---|---|---|
| Посмотреть на куклу / на стол сверху | крестовина ▲ / ▼ | **W** / **S** |
| Повернуть голову влево / вправо | крестовина ◀ / ▶ | **A** / **D** |
| Вращать камеру вокруг стола | тянуть пальцем | тянуть мышью |
| Приблизить / отдалить | щипок двумя пальцами | колесо мыши, **+** / **−** |

- **Шестерёнка** в левом верхнем углу открывает меню: новая игра, звук, громкость (общая, музыка, фоновый звук), подсказки и 😁, который делает кнопку «Сдаться» видимой всегда.
- **Белый флаг** «Сдаться» в правом нижнем углу появляется сам, когда ваше положение становится безнадёжным.
- Звук и музыка включены сразу. Если браузер не дал им заиграть, просто коснитесь экрана или нажмите любую клавишу. Выключить звук можно в меню.

## Как это сделано

- Вся сцена — руки, фигуры, доска, стол, карты, глаза и рот — рисуется одним фрагментным шейдером WebGL2 методом ray marching по полям расстояний (SDF), в низком разрешении с пиксельным дизерингом.
- Руки собраны из капсул и шаровых шарниров. Движение считается обратной кинематикой: плечо, локоть, запястье, фаланги пальцев.
- Шахматные правила и соперник написаны на чистом JavaScript: генерация ходов, проверка шаха и поиск на два полухода вперёд.
- Звуки и фоновая музыка синтезируются в браузере через Web Audio, без аудиофайлов.
- Из внешних ресурсов подключаются только шрифты Google Fonts; без интернета будут резервные шрифты.
- Настройки громкости и подсказок сохраняются в `localStorage` браузера.
